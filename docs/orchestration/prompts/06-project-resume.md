# Project Resume Prompt

```text
Resume the project from repository evidence, not memory.

First read:
- README and architecture documents;
- progress, pending decisions, roadmap, and current story;
- validation evidence and recent commits;
- Git branch, status, log, and remotes.

Reconstruct:
- current version and completed increments;
- active acceptance criteria;
- open findings and human decisions;
- exact last verified gate.

Continue only the already authorized work. Do not repeat completed work unless evidence is missing or inconsistent. Stop for material ambiguity, scope change, external action, or unresolved Critical/High finding.
```
