# SupportOps Command Center 1.0.0 — Local Release Notes

Status: demonstrable release candidate; no tag, GitHub release or publication.

V1 delivers the complete offline flow from SQLite incident registration through
deterministic triage/runbook search, performed-procedure audit, nine-section ticket
documentation, safe Markdown/JSON export and Streamlit dashboard. Python 3.12 and
Windows are the primary local path; Docker provides a non-root container with
separate persistent volumes.

Install with `uv sync --locked --extra dev`, initialize using `supportops db init`,
and run the web app with `uv run streamlit run src/supportops/streamlit_app.py`.
Container users run `docker compose up -d` and browse loopback port 8501.

Upgrade from 0.6.0 changes package version and delivery/docs only; it does not add
a migration or change approved business behavior. Existing v4 SQLite databases
remain compatible. Back up database and exports before changing environments.

Validation evidence is recorded under `docs/testing/evidence/ST-08.md`. Known
limitations include local SQLite scaling, unauthenticated actor labels,
irreversible soft deletion, lexical search boundaries and no ticket/LLM integration.
A license/security contact and every external publication action remain pending.
