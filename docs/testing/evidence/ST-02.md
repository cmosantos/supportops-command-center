## QA-blocking regression fixes

- Deterministic event order: migration v1 has positive `sequence` and unique
  `(incident_id, sequence)`; repository calculates `MAX(sequence)+1` in the same
  Unit of Work and history orders by sequence.
- A fixed-clock/adversarial-ID test proves event order `1,2,3` independent of
  timestamp and identifier ordering.
- Exact approval matching now additionally requires `decision='APPROVED'`; real
  SQLite parameterized tests prove PENDING and REJECTED return false.
- Fault injection raises `sqlite3.IntegrityError` after projection update and
  before event append; both projection and history remain unchanged after rollback.
- A real orphan event insert raises `sqlite3.IntegrityError`; rollback leaves zero
  event rows, proving per-connection FK enforcement.
