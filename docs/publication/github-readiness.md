## Human-controlled checklist

- [ ] Select repository visibility and create the repository.
- [ ] Confirm `main` as default branch and configure protected-branch reviews/checks.
- [ ] Select a definitive license and add `LICENSE`.
- [ ] Select and publish a real private security contact in `SECURITY.md`.
- [ ] Review README, sanitized demo, screenshots and all tracked-file scans.
- [ ] Configure remote and push only after explicit authorization.
- [ ] Observe a green GitHub Actions run (local review is not remote evidence).
- [ ] Review dependency/security alerts and retention/privacy expectations.
- [ ] Deliberately create signed/annotated tag and GitHub release if approved.
- [ ] Decide separately whether container/package publication is appropriate.
