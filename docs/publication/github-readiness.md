## Human-controlled checklist

- [ ] Create a **public** repository named `supportops-command-center` without auto-generating README, `.gitignore`, or license files.
- [ ] Confirm `main` as the default branch and configure protected-branch reviews/checks.
- [ ] Select a definitive license and add `LICENSE`.
- [ ] Select and publish a real private security contact in `SECURITY.md`.
- [ ] Review README, synthetic demo, screenshots, orchestration templates, and tracked-file scans.
- [ ] Configure remote and push only after explicit authorization.
- [ ] Observe a green GitHub Actions run; local evidence is not remote CI evidence.
- [ ] Review dependency/security alerts and retention/privacy expectations.
- [ ] Deliberately create an annotated tag and GitHub release if approved.
- [ ] Decide separately whether container or package publication is appropriate.
- [ ] Export a raster social-preview image from `docs/assets/supportops-banner.svg`.
- [ ] Add the final GitHub link and screenshot to the Lovable portfolio only after repository review.
