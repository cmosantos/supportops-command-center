# Portfolio Card Copy

## Title

SupportOps Command Center

## Short description

A local-first incident operations platform for N1/N2 support teams, combining deterministic triage, offline runbooks, auditable procedures, structured ticket documentation, safe exports, and an operational dashboard.

## Technology labels

`Python 3.12` · `Streamlit` · `SQLite` · `Docker` · `Pytest` · `MyPy` · `Ruff` · `GitHub Actions`

## Key highlights

- Deterministic 4×4 priority matrix and evidence gaps
- Five packaged support runbooks
- Immutable lifecycle, triage, procedure, and document history
- GLPI/ServiceNow-ready documentation
- Safe Markdown and JSON exports
- Non-root Docker delivery with persistent volumes
- 256 tests passed in the recorded V1 validation campaign
- AI-assisted engineering with human-controlled gates
